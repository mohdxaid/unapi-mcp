# Pre-Built Site Catalogs (`sites/`)

This directory contains ready-to-use, sanitized API catalogs generated by `unapi-mcp`. You can load any of these directly into the MCP server, spin them up as an offline mock server, or export them to Python/TypeScript SDKs:

```bash
# Start an MCP server with a specific pre-built catalog
npx unapi-mcp mcp --catalog ./sites/hackernews.json

# Copy all pre-built catalogs into your local ~/.unapi-mcp/catalogs store
cp sites/*.json ~/.unapi-mcp/catalogs/
npx unapi-mcp list
```
