# Examples (`examples/`)

This folder shows what `unapi-mcp` generates from live websites:

- `acme-flights-client.ts` — Auto-generated zero-dependency TypeScript SDK (`unapi-mcp export acme-flights --format ts`).
- `acme-flights-client.py` — Auto-generated zero-dependency Python SDK (`unapi-mcp export acme-flights --format python`).
